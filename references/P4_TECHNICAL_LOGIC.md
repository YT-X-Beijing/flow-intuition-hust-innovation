# P4 技术逻辑约束

本文件用于约束 P4 的技术模块、层级与交互关系。修改 P4 时不得以概括性表达替换以下结构。

## 整体层级

1. 存算一体芯片适配
2. 世界记忆驱动的可塑动作模型 + 面向物理 AI 的自进化记忆框架
3. 群体智能进化
4. 全形态具身适配

## 世界记忆驱动的可塑动作模型

- 多模态输入：视觉观测、语言目标、动作历史/本体状态、记忆上下文
- 记忆原生统一模型：记忆路由·写入门控、世界模型想象头、动作决策头、价值与自检头
- 交替推理与输出：想象→决策循环展开、具身执行·环境反馈、记忆写入·自进化、新观测·收益信号

## 模型与记忆的双向交互

- 写入路径：动作结果、RPE 评估、情节巩固抽象
- 环状双循环共同进化
- 读取路径：记忆检索、决策注入、想象推演

## 面向物理 AI 的自进化记忆框架

- 核心原则：以世界模型为核心、惊讶驱动、适时总结、用进废退、举一反三
- 记忆层级：情节记忆 → 语义/物理记忆 → 技能图式
- 多维 RPE：状态、任务、接触、约束、置信度失配
- 惊讶驱动：多维 RPE 识别高价值经验
- 适时总结：时间步-轨迹-任务-机制分层巩固
- 用进废退：LTP/LTD 强化、修订、遗忘
- 举一反三：想象空间类比组合、主动探索

## 禁止替换为以下错误结构

- `结果预测 → 真实反馈 → RPE` 不能替代原 BP 的完整右侧架构。
- 记忆层级不得改为 `情节经验 → 技能图式 → 语义/物理知识`。
- 不得在本页用“记忆控制：检索、更新、保留、删除”替代四项演化机制。
